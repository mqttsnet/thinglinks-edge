# Protocol components and templates implementation plan

Target version: 1.0.3
Created: 2026-09-09

**Goal:** Select, configure and deploy reusable acquisition templates with explicit driver dependencies.
**Architecture:** Pure protocol/recipe definitions; persistence and deployment services; thin authenticated HTTP routes; composed Vue forms.
**Tech Stack:** Node 22.18+/24.12+, TypeScript 5.9, Fastify, SQLite, Node-RED, Vue and Naive UI.
**Spec:** [Design and contracts](../specs/v1.0.3-protocol-templates-design.md)

## Constraints

Preserve `.ts` relative imports, existing custom template API behavior, existing instances and package approval rules. Follow the user's current authorization for local commits and deployment; pushing remains a separate action. Runtime tests use task-owned isolated resources only. Tests precede behavioral implementation.

This checklist preserves the original task breakdown. Current source and the [later wire acceptance record](../../verification/protocol-wire-nodered-20260910.md) determine implementation and verification status; unchecked historical planning entries are not a claim that current code is absent.
