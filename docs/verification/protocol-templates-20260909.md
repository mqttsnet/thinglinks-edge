## 实际 Node-RED 与模拟设备

Node-RED 镜像：`nodered/node-red:5.0.4-24-minimal`，Linux arm64，Node 24.18.1。

固定安装：Modbus 5.60.2、OPC UA 0.2.355、S7 3.1.3、ThingLinks 平台节点 0.0.1。安装阶段仅连本轮内部网络的离线 registry；完整闭包为 342 个已校验原始包，20,479,857 字节。

早期隔离运行中的七个采集场景均通过：TCP、UDP、HTTP 定时采集、HTTP 推送、Modbus-TCP、OPC UA、S7。

- 实际协议节点采到模拟设备值，经过真实 `tl-uplink` 到测试收数端。
- 真实 MQTT Broker → 当前 `CloudGateway` / `CommandBridge` → Node-RED → 协议写入 → 模拟设备确认 → 标准 MQTT 回执。
- 命令使用约 `4.8e17` 的 Cloud Snowflake 量级 MID。回执保持同一个不带引号的 JSON 整数 token。
- 各场景的同 MID 重复投递均未再次写设备；非法数值参数均未改变设备。
- 早期隔离实验中 Modbus 和 OPC UA 断联、恢复及同 MID 再投递均未重放旧写操作；其中 OPC UA 依赖通用执行节点，不覆盖默认受管实例，当前控制仍未通过。
- 追加流程后测试实例的既有节点保持不变。

命令运行测试使用当前桥接源码与测试用 SQLite 适配器；生产 better-sqlite3 路径另由源测试及镜像原生模块检查覆盖。
