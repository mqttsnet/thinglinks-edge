# 现场设备状态与云端同步

设备在线、采集流程运行、Edge 的 MQTT 连接是三件不同的事。实例启动、节点显示绿色或 MQTT 重连本身，不代表设备已恢复采集。

## 多个采集来源

新模板为每条采集流程登记独立观察者。同一实例的多个流程可以采集同一设备，状态按来源合并：任一来源在线则保持在线；全部来源明确不可用才请求离线；没有在线来源且存在未知来源时，现场页面显示“等待采集确认”。不同实例之间也保留多来源判断。

这里的在线表示有有效采样证据且采集通信尚未判为不可用，不代表物理电源状态。持续 OPC UA 会话建立失败，包括明确的证书或身份握手拒绝，会按连续失败窗口判为通信不可用；单点 Bad 质量、地址错误或队列繁忙不直接使用该规则。

云端状态沿用网关标准 `topo/update` 通道。归属校验通过、响应中该设备明确成功后，才记为同步成功。点位地址、格式、权限或质量错误不能一概当作物理断网，协议事件需按组件版本分类。

## 静止数据与流程失联

S7 的变化上报模式采用“变化时立即上报，每 60 秒完整同步”。模板继续周期读取 PLC；两个完整同步周期之间，未变化的真实样本更新现场当前值、采集时间和在线证据，不重复进入云端批次或补传。周期完整同步用于修复某次提交失败后的缺值，不把节点消息透传当作 Manager 已成功接收。本地历史仍遵循本地历史自身的采样策略。

OPC UA 兼容模板的订阅模式默认每 60 秒通过独立原生客户端读取同一组点位。它提供静止值下的新采样证据，主订阅与健康读取各有自己的观察者，任一健康来源可维持设备在线。该选项需要额外 OPC UA 会话；高级配置可调整周期，设为 0 关闭。关闭后，云连接恢复需等待新的订阅通知；会话额度不足时可选择定时读取模式。

UDP 和 HTTP 推送没有通用的连接在线语义。没有明确配置设备上报超时规则时，不因数据静默自动下线。

采集流程另有运行租约：默认每 10 秒续约，60 秒没有成功续约后，该采集来源视为不可用。这用于识别删除流程、关闭节点或流程与 Manager 失联，不依赖设备的上报频率。续约只证明流程仍在运行，不生成新采样或云端在线证据。周期检查最多约增加 5 秒延迟，协议节点自身的断线检测与云端确认还受设备、网络和重试影响。短暂暂停实例保留运行代次并沿用租约宽限；超过租期仍会使该来源不可用，恢复时须等待新的采样。控制台会独立标注“实例已暂停”。

确认不可用期间，流程每 5 秒重发带新序号的离线观察，避免唯一一次状态请求丢失后永久在线。恢复采集后停止重发，旧序号的离线请求不能覆盖新数据。

租约过期后，续约会换发运行代次，旧代次的采样全部拒绝。模板不缓存启动或代次切换期间的采样，等待新采样恢复在线。

## 升级与已有流程

更新 Manager 不会重写已部署的流程。通过新内置模板重新预览、部署后，才具有对应的观察者逻辑。

同一设备启用观察者后，旧节点独立发送的状态或无观察元数据的值不能覆盖新的状态判断。旧数据入口仍兼容数据接收。混用新旧流程时，应把需要参与状态判断的采集来源一并纳入新模板。

## 内部接口与扩展

模板复用标准 Function、HTTP Request、Status、Catch 等 Node-RED 节点，工业协议仍由原有协议组件处理。平台节点 `@mqttsnet/thinglinks-edge-nodes@0.0.1` 的发布包和完整性校验值保持不变。

所有观察者接口使用每实例独立的接入令牌，实例身份只从令牌反查：

| 接口 | 作用 |
| --- | --- |
| `POST /api/edge/observers/challenge` | 取得本次运行的启动凭据，固定其前置版本 |
| `POST /api/edge/observers/activate` | 比较前置版本后激活；旧运行不能重新抢占 |
| `POST /api/edge/observers/renew` | 续约；过期时换代，不把续约当采样 |
| `POST /api/edge/uplink` | 统一接收有序采样或离线观察 |

启动凭据、运行代次和最后接收序号持久化。Manager 重启不会接受旧序号，也不会从存储直接恢复在线证据。已经确认的本地离线状态会继续参与同步，即使云连接在本地服务启动后才恢复，也不会丢失待补发的离线责任。

新模板通过原有 `tl-uplink` 提交内部版本化封套。Manager 解包后按原来的服务、属性和批次规则上报；观察元数据不进入云端点位或补传。`__tlePresence` 是保留字段，不能作为普通物模型属性：

```json
{
  "__tlePresence": {
    "version": 1,
    "observerId": "collector-a",
    "runNonce": "run-a",
    "generation": 2,
    "sequence": 18,
    "kind": "sample",
    "report": true
  },
  "values": { "temperature": 26.5 }
}
```

`sample.report` 默认为 `true`，`false` 表示真实采样只更新现场数据和在线证据。离线观察使用 `kind:"status", online:false`，不得携带 `values`；在线必须来自有效采样。

格式错误返回 400；过期代次、重复或倒序事件返回 409，旧采样不会更新当前值。启动请求通过固定错误编码区分过期启动凭据与运行冲突，仅前者可以使用同一本次运行标识重新申请凭据。

每实例最多登记 512 台设备、1024 个观察者、4096 条运行记录；全局另有 10000 台设备、10000 个观察者、50000 条运行记录的保护上限。单实例超过自己的额度时只拒绝其新登记，其他实例仍可登记，已有的采集、续租继续运行。来源未能完整登记时保留待核对状态，避免丢失来源导致错误离线。旧运行记录保留用于阻止回放；删除实例时随实例级联清理。
